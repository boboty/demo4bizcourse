# 四 Demo 课堂手卡

打印或现场查看用。所有操作名称按当前界面；技术详情、原始 JSON 和接口调试不在主线。每个 Demo 的完整备课及故障处理见对应 runbook。

## A｜第 17 页演示 → 第 18 页回顾

**核心问题：**识别出敏感字段后，谁决定能否处理？

| 操作什么 | 看什么 | 讲什么 |
| --- | --- | --- |
| 1. 点击“运行规则识别” | 原文高亮和右侧分类证据 | 规则给出基线，分类不等于授权。 |
| 2. 点击“查看辅助识别” | “128000 元”被误报为个人信息 | 固定离线模拟可能误报；金额本身能识别自然人吗？停顿提问。 |
| 3. 保持“一般业务资料”及默认理由，点击“确认人工修正” | 误报改为一般业务资料 | 人依据原文修正；修正不赋予权限。 |
| 4. 点击“申请脱敏预览” | 原文与处理结果对照 | 看哪些字段遮盖、哪些业务字段保留；脱敏不等于匿名化。 |
| 5. 点击“人工确认并完成脱敏” | 处理完成和审计结果 | 人确认后才进入下一步。收口：授权由后端独立决定。 |

**衔接/时间：**第 16 页受控数据流转入，第 18 页回顾；完整 12–15 分钟：纯操作 4–6 分钟，讲解互动 8–9 分钟。**复位：**顶部“重置演示”。**最简备用：**只演示规则→误报→人工修正，口头讲预览和确认；如页面不可用，继续课件，不冒充实机演示。

## B｜第 30 页演示

**核心问题：**被污染文档改变模型提案后，谁挡住越权动作？

| 操作什么 | 看什么 | 讲什么 |
| --- | --- | --- |
| 1. 点击“重置演示”，再点击“运行正常查询” | 请求、正常只读提案、安全结果和待审批状态 | 建立只读基线。 |
| 2. 点击“检索污染文档” | 同一请求、注入文档、审批写提案 | 不可信文档是数据，不是系统指令。 |
| 3. 停在提案卡，问学员会不会执行 | 目标对象和待执行动作 | 模型建议与系统许可不同。 |
| 4. 点击“故障模式：执行越权提案” | 故障侧变“已批准” | 故障示范跳过授权并改变隔离单据。 |
| 5. 点击“安全模式：执行同一提案” | 安全侧拒绝，仍待审批 | 后端按身份、对象、动作授权；审计可追踪。 |

**衔接/时间：**第 29 页预测转入，第 31 页讲拦截；完整 12–15 分钟：纯操作 3–5 分钟，讲解互动 9–10 分钟。说明课件登录/四工具与固定身份及两类工具动作的教学适配。**复位：**顶部“重置演示”。**最简备用：**聚焦同一污染提案的故障/安全执行对照。

## C｜第 45 页演示 → 第 46 页回顾

**核心问题：**规则线索和 AI 解释怎样变成有证据的人工认定？

| 操作什么 | 看什么 | 讲什么 |
| --- | --- | --- |
| 1. 点击“建立审计案例” | 默认案例业务背景和审计对象 | 先认清审计对象。 |
| 2. 点击“查看规则线索” | 规则线索和相关依据 | 命中是待查线索，不是违规结论。停顿请学员说还缺什么。 |
| 3. 点击“生成辅助解释” | 离线解释、待核实项、证据卡 | AI 解释帮助定位，仍需看原文。 |
| 4. 阅读证据原文、勾选核对项，点击“记录证据核对” | 核对状态及材料完整性 | 对照日志、审批和制度；关键字段缺失可判证据不足。 |
| 5. 选结论、填写理由，点击“提交人工认定” | 人工结论及关联证据 | 只有人工提交才形成最终认定。 |

**衔接/时间：**第 44 页角色分工→45 演示→46 证据阶梯；完整 15–18 分钟：纯操作 5–7 分钟，讲解互动 10–11 分钟。可选：点击“导出候选问题清单 JSON”，无需展示 JSON。**复位：**“重置 C”。**最简备用：**进行到证据核对，强调结论仍待人提交。

## D｜第 54 页演示 → 第 55 页回顾

**核心问题：**AI 怎样辅助研判，又如何把事实和推测分开？

| 操作什么 | 看什么 | 讲什么 |
| --- | --- | --- |
| 1. 点击“汇总日志线索” | 认证、API、权限审计三类合成记录 | 分散记录先汇总，样本是虚构的。 |
| 2. 点击“聚合异常事件” | 候选事件和未命中数量 | 规则负责稳定关联，未命中不等于正常。 |
| 3. 点击“生成辅助研判” | AI 解释、日志引用和待核实推测 | 推测不是事实。停顿让学员指出证据边界。 |
| 4. 选择判断、引用相关日志、写理由，点击“提交人工核查” | 已记录人工核查和结论边界 | 核对原始日志能证明什么、还缺什么。 |
| 5. 点击“生成四栏简报” | 事实、推测、待核查、建议动作 | 建议只是文本，不会执行处置。 |

**衔接/时间：**第 53 页职责泳道→54 演示→55 四栏回顾；完整 15–18 分钟：纯操作 5–7 分钟，讲解互动 10–11 分钟。可选下载“导出四栏简报 JSON”。**复位：**“重置 D”。**最简备用：**展示线索聚合与 AI 待核实卡，口头完成四栏释义。
