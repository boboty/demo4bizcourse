# Demo A 讲师操作剧本

建议 20 分钟。全部资料和身份为本机固定虚构示例。辅助识别是离线确定性教学模拟，不连接或调用真实模型；演示不承诺通用识别能力。

## 课前准备

1. 依赖预装后，在 `ai-security-demo/` 执行 `make dev`，打开 `http://127.0.0.1:8016/demo/a`。单应用同时提供 A/B/C/D。
2. 建议 1440×900 或更大窗口全屏投影。点击“重置 A 演示”，确认运行与审计为空。
3. 不输入真实合同、个人信息或涉密内容。涉密示例只有固定 ID、分类标签和拒绝原因，不提供正文。

## 分步演示与停顿

| 操作 / 停顿点 | 屏幕预期 | 讲师说明 |
| --- | --- | --- |
| 1. 选择“已有处理授权”合同，点“1 规则检查” | 展示固定合同、字段位置、证据与普通 / 个人 / 商业分类 | 规则提供可重复基线，不会授予处理权限。 |
| 2. 点“2 离线辅助识别” | `128000 元` 被固定模拟误报为个人信息，展示误报 ID、证据和解释 | 明确这是离线确定性示例，不是真实模型输出。请指出金额本身不能识别自然人。 |
| 3. 修改证据或类别后尝试“3 人工修正误报” | 服务端仅接受与固定误报逐项匹配的证据、类别及非空理由；任意证据被拒绝 | 让学员回到原文核查。参考理由：“合同金额是一般业务字段，不足以识别自然人身份。” |
| 4. 点“4 脱敏预览” | 有授权资料显示原文和脱敏预览；标明尚未进入下一步 | 预览只是本地展示，脱敏不保证匿名化，也不自动许可后续处理。 |
| 5. 停顿后点“5 人工确认进入下一步” | 后端才完成本地处理动作并追加审计 | 是否进入后续允许流程由人确认，复演脚本不会自动点击此按钮。 |
| 6. 选择“已识别但未授权”并运行规则、辅助识别、人工修正、预览 | 修正后预览仍被固定授权策略拒绝，不生成脱敏文本 | 识别和人工修正均不能改变后端资料权限。 |
| 7. 点“检查涉密链路阻断” | 识别、脱敏、上传均返回 403 / `CONFIDENTIAL_BOUNDARY`，正文未提供 | 涉密资料在普通处理链之前阻断。 |
| 8. 下滚查看 A 专属审计，再切换 B 页面 | 可见固定身份、资料 ID、动作、结果和 request_id；B 状态不被 A 操作改变 | 日志只记元数据；各 Demo 入口始终可切换。 |
| 9. 点“自动演示到人工核对” | 自动重置、运行规则及辅助识别后停在修正前 | 之后由讲师手动修正、预览并决定是否确认。 |

## 故障备用路径

| 故障 | 操作与预期 |
| --- | --- |
| 请求失败或有红色错误和 request ID | 查看 `make dev` 启动终端；服务恢复后刷新页面并点“重置 A 演示”。错误由页面明确显示，不继续到人工确认。 |
| 流程跟不上讲解 | 点重置后逐步点击规则、辅助识别、人工修正、预览和确认，每一步暂停。 |
| 8016 端口占用 | 先确认占用进程归属；课堂入口约定 8016。若改用 8017，按 URL 手动打开并将备用 HTTP 命令指向该服务，不停止来源不明的进程。 |
| 浏览器无法操作 | 在服务已启动时运行 `uv run --offline python scripts/http_smoke_a.py` 演示真实 HTTP；明确说明当前是接口备用路径。 |
| 服务或依赖未就绪 | 使用本地静态课件继续讲授，待服务恢复后现场重跑。无录屏；不把历史截图说成当前演练。 |

课堂结论：规则和辅助识别都可能有误报或漏检；人应核查原始证据并修正。授权由后端独立决定，下一步由人明确确认，涉密资料不进入普通链。
