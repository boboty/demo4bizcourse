# Demo A 讲师操作剧本：敏感数据识别、授权与脱敏

对应定稿课件第 17 页现场演示、第 18 页回顾。建议完整课堂环节 12–15 分钟，其中纯操作约 4–6 分钟，讲解、提问和停顿约 8–9 分钟；可选深入讨论另行调配，不计入此区间。合同、身份及字段均为本机固定虚构数据；辅助识别为离线确定性教学模拟，不是真实模型输出。

## 起点与课前准备

在第 16 页讲完受控数据流与红线后切到 `/demo/a`。课前已启动单机服务；确认本地服务健康，按页面“重置演示”，原文显示固定合同，下一步提示“运行后端规则识别”。页面顶栏可转到 B/C/D。不得输入真实合同、个人信息或涉密内容。涉密示例没有正文。

## 课堂主线

| 操作 / 停顿点 | 屏幕应看到什么 | 讲师说明 |
| --- | --- | --- |
| 1. 点击“运行规则识别” | 合同原文中的字段高亮，右侧字段分类证据同步出现 | 规则给出可重复的识别基线；分类不等于授权。请学员指出哪些是个人信息、哪些是商业敏感。 |
| 2. 点击“查看辅助识别” | “128000 元”作为个人信息误报出现，页面显示辅助解释与待核对内容 | 这是固定模拟误报，不代表模型每次都这样。请问：金额本身能识别自然人吗？ |
| 3. 保持“一般业务资料”和默认核对理由，点击“确认人工修正” | 误报被修正为一般业务资料；结论提示接下来由后端检查授权 | 人核对原文并说明理由；人工修正改变分类结论，不创建处理权限。 |
| 4. 点击“申请脱敏预览” | 页面出现原文与后端处理结果对照；预览尚未完成后续动作 | 先停顿比较：直接标识符被遮盖，业务字段仍保留。脱敏不保证匿名化，也不是上传许可。 |
| 5. 点击“人工确认并完成脱敏” | 页面显示处理完成与审计记录 | 是否进入下一步由人明确确认；这里才完成本地处理动作。 |

**关键转折：**辅助识别把一般合同金额误判为个人信息；人按原文证据修正后，后端授权仍单独控制处理。可选安全边界分支在主线之后：点击“演示未授权拒绝”，看到后端拒绝且不产生脱敏文本；“演示涉密前置阻断”展示识别、脱敏、上传均被前置阻断。只选一个分支即可；两条边界分支均为可选深入内容。

## 收口与复位

回到第 18 页口头回顾“识别 → 人工核对 → 授权检查 → 脱敏 → 人工确认”。结论：识别可能误报或漏检，授权由后端独立决定，处理下一步需要人确认，涉密资料不进入普通链路。点“重置演示”可清空 A 本轮运行与审计；刷新或重启单进程服务也恢复内存初态，不影响 B/C/D。

## 技术备用（不放入课堂主线）

若浏览器不可用而服务仍在运行，可用 `uv run --offline python scripts/http_smoke_a.py` 做 HTTP 备用演示；这是接口检查路径，不冒充正常页面体验。请求失败时读页面错误提示与请求标识，查看服务终端，恢复后刷新并重置 A。端口 8016 被占用时按 `CLASSROOM_ENV_CHECKLIST.md` 处理。
