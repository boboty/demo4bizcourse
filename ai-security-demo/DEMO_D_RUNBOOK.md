# Demo D 讲师操作剧本：AI 辅助日志分析与证据分层

## 本讲目标

学员会看见小规模账号认证、API 网关和授权日志如何形成可复核线索；辨认离线模拟 AI 的推测与日志直接支持的事实；再用原始日志和理由处置一条线索，生成分栏简报。所有记录、身份、IP、平台和企业背景均为合成课堂数据，不代表真实事件。

## 开课前

运行 `make dev`，在浏览器打开 `http://127.0.0.1:8016/demo/d`。页面健康状态应显示本地服务正常、外部服务未连接。检查四个入口和原始日志表可见。时间列表示合成样本中的上海本地墙钟时间（UTC+08:00），不代表真实采集时间。确认页面无外部字体、模型 API 或 CDN 依赖。

## 演示步骤（约 12 分钟）

1. **先看原始日志（2 分钟）**：开始分析后读十条稳定 ID 样本。强调只包含账号、来源 IP、事件类型、说明和合成时间，没有响应字节数、凭据来源或出口流量。
2. **运行规则（3 分钟）**：依次指出 5 分钟内重复登录、非工作时段成功登录、连续权限拒绝三条规则。`svc-report-02` 的两次登录来自报表服务正常重试背景，提醒学员“命中”也可能是误报；`LOG-D-004/005` 是工作时段普通记录，可作正常参照。规则只基于当前样本，不断言入侵。
3. **观察模拟 AI（2 分钟）**：离线确定性解释器会把相关日志列成候选事件，并提出“凭据可能泄露且已通过 API 外传”。请学员指出证据缺口：登录时间、API 读取和拒绝日志并不直接证明身份凭据来源、读取了什么、传输了多少或流向哪里。
4. **人工核对并修正（3 分钟）**：默认选中越证 AI 推测。核对关联原始日志，保留“排除 AI 推测”，填写具体理由，例如“样本没有凭据来源、响应体积或出口流量，不能支持账号失陷或数据外传”，提交。也可选报表服务频率线索作为误报候选，按上下文核查后排除；或者选择“待补证”。“确认线索”仅确认可观察异常，不是确认账号失陷或数据泄露。
5. **查看四栏简报（2 分钟）**：生成并可下载 JSON。事实栏有日志观察和固定演示人工核查记录；AI 推测栏标注人工排除、待补证或仍未证实；待核查栏列出缺失的源数据；建议动作是文本建议，页面和服务没有账号封禁、系统隔离或生产变更执行接口。点证据 ID 可回到原始日志。

## 复演、重置与预期

点击“一键复演至人工核查前”会先清空本课状态，再完成日志汇总、规则分析与离线模拟分析，停在人工核查按钮之前。手动完成核查和简报后点“重置 D 演示”：运行、人工结果、简报和本课审计被清空，旧 run ID 返回 404。A/B/C 的运行和审计保留。

预期候选规则：`svc-report-02` 命中 5 分钟重复登录，`user-demo-22` 命中非工作时段登录，`user-demo-31` 命中连续权限拒绝；正常参照至少包括 `LOG-D-004`。模拟 AI 每次会展示带稳定 ID 的越证推测；推测不会自动写入“已证实事实”。固定服务端核查身份 `sec-reviewer-008 / security_log_reviewer` 不可从请求正文更改。每项人工操作和阶段动作会在审计里显示对象、动作、结果、run/request ID。

## 故障兜底

- **页面服务不可用**：检查 Uvicorn 是否监听 `127.0.0.1:8016`；必要时重启 `make dev`，再重新打开页面。
- **阶段顺序冲突**：读取提示中的阶段要求，点击独立重置后从头演示。重置不会触碰其他 Demo。
- **人工核查被拒绝**：确认选择的是本次运行的线索、至少勾选一个与线索直接相关的日志 ID、理由非空；不要手写未知或伪造 ID。
- **浏览器无法加载**：全部资源由本地 FastAPI 提供；确认 `/static/demo-d.js`、`/static/demo-d.css` 和 `/static/design-system/styles.css` 返回 200，不需要外网。
- **学员询问是否真实事件**：明确说明所有数据均为合成演示，不对真实账号采取任何动作，不用它作生产判断。
