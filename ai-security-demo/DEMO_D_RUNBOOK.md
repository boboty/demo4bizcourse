# Demo D 讲师操作剧本：合成日志分析与人工核查

对应第 54 页演示，前接第 52–53 页安全运营闭环和职责泳道，后接第 55 页四栏回顾。完整课堂环节建议 15–18 分钟，纯操作约 5–7 分钟，讲解、证据核对和讨论约 10–11 分钟；可选深入讨论另行调配，不计入此区间。日志为虚构合成样本；AI 分析是离线模拟，不连接真实平台，课堂不会封禁账号或隔离系统。

## 起点与课堂主线

从安全运营闭环中“只有授权处置会真正改变系统”的讲解进入 `/demo/d`。确认健康状态正常，必要时点击“重置 D”。

| 操作 / 停顿点 | 屏幕应看到什么 | 讲师说明 |
| --- | --- | --- |
| 1. 点击“汇总日志线索” | 认证、API 网关、权限审计三类合成信号被放入同一工作区 | 分散记录先汇总；这不是生产日志，也不应据此判断真实账号。 |
| 2. 点击“聚合异常事件” | 确定性规则把相关记录归成候选事件，并显示未命中记录数量 | 规则可重复地按字段关联线索；未命中不等于正常。 |
| 3. 点击“生成辅助研判” | AI 辅助解释、相关日志引用、待核实推测出现 | “凭据泄露/数据外传”等内容仍是推测，不是已证实事实。请学员指出证据支持到哪一步。 |
| 4. 选择核查对象与人工判断，引用相关原始日志并写理由，再点击“提交人工核查” | 页面记录人工核查结果，显示结论边界 | 对照原始日志，指出一项证据不足或排除的推测；日志只能证明实际记录的事件。 |
| 5. 点击“生成四栏简报” | 事实、AI 推测、待核查事项、建议动作四栏出现 | 建议动作只是文本，不会执行封禁或隔离。第 55 页按四栏复盘来源与授权要求。 |

可在主线末尾点击“导出四栏简报 JSON”下载。完整日志、运行 JSON 和审计位于技术详情中，属于可选深入材料。

## 收口与复位

结论：确定性规则负责归并，AI 帮助整理解释，人工核查确认边界，处置必须另有组织授权。点击“重置 D”清空 D 本轮运行、简报与审计；不会影响 A/B/C。重启服务恢复内存初态。

## 技术备用

浏览器故障但服务正常时，可运行 `uv run --offline python scripts/http_smoke_d.py` 作为 HTTP 备用路径。服务错误看页面请求标识与启动终端；恢复后刷新并重置 D。端口处理见 `CLASSROOM_ENV_CHECKLIST.md`。
