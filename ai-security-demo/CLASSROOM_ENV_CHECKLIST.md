# 离线课堂环境检查清单

范围：本机单人课堂；FastAPI 单进程监听 `127.0.0.1:8016`，A/B/C/D 四入口共用一个服务。依赖需课前预装；启动后页面与静态资源从本地提供，不需要云模型。进程内状态仅供课堂使用，服务重启即恢复初态。

## 课前启动（建议断网复核）

- [ ] 已在有网络时于 `ai-security-demo/` 执行过 `make setup`，Python 3.12 与 uv 环境准备完成；课堂现场不安装依赖。
- [ ] 断网后执行 `make dev`。Makefile 使用 `uv run --offline uvicorn ...`；保持该终端运行，不加 `--workers`。
- [ ] 浏览器打开下列四路由，确认页面加载、本地服务健康提示正常，四个页面都可见 A/B/C/D 导航：

  - `http://127.0.0.1:8016/demo/a`
  - `http://127.0.0.1:8016/demo/b`
  - `http://127.0.0.1:8016/demo/c`
  - `http://127.0.0.1:8016/demo/d`

- [ ] 离线验证静态资源和四路由：在服务运行时执行 `uv run --offline python scripts/http_smoke_integrated.py`。该脚本是真实 HTTP 集成检查，会验证四路课堂链和独立重置；结束后核对页面初态。此为实际验证命令，不要求现场重复完整自动化。
- [ ] 可选检查无需运行时外网资源：浏览器开发者网络面板确认 CSS、JS、图标均为本机 URL，无 CDN/在线字体请求；代码中使用同源 `/static` 资源，页面图标为内联 `data:,`。

## 课堂故障处理

| 现象 | 处理 |
| --- | --- |
| 页面按钮请求失败 | 记录页面错误/请求标识；查看 `make dev` 终端。恢复服务后刷新当前路由并仅重置当前 Demo。 |
| 服务退出或状态错乱 | 在原终端 Ctrl+C 后重新执行 `make dev`；重新打开路由。单进程内存状态会恢复初态；四个 Demo 再分别确认状态。 |
| 8016 端口占用 | 不终止来源不明的进程。先查清占用者和归属；若是本课程遗留服务，正常停止后重启。若无法释放，可执行 `uv run --offline uvicorn app.main:app --host 127.0.0.1 --port 8017`，讲师手动打开 8017 的路由；现有 HTTP smoke 脚本默认使用 8016 端口，不能直接用于 8017。恢复标准端口后再运行自动检查。 |
| 浏览器不可用、服务正常 | 按相应 runbook 使用已存在的 `scripts/http_smoke_*.py` 作技术备用，并明确这是 HTTP 接口演示，不是页面流程。 |
| 服务无法恢复 | 继续定稿课件和 runbook 讲授；不要把历史截图、旧 smoke 输出说成实时运行。 |

## 独立重置与课后

- A：页面顶部“重置演示”；B：页面顶部“重置演示”；C：“重置 C”；D：“重置 D”。重置只清理相应 Demo 的状态，不影响其他三项。
- 课后分别重置四个 Demo；若要保存课堂证据，先按课程资料管理要求保存，再关闭服务。启动终端按 Ctrl+C 停止。关闭后可留存本地课件、讲师剧本、手卡及本次经授权保存的材料。
- 不收集或保留真实个人信息、合同或涉密数据；运行数据为内存状态，正常关闭或进程重启即清空。

## 当前环境复核依据

- `Makefile`：`setup` 使用 `uv sync --python 3.12`；`dev` 使用离线模式并绑定回环地址的 8016；`check` 和 `test` 使用 `uv run --offline`。
- `app/main.py` 与 `app/static/`：同一 FastAPI 服务挂载 A/B/C/D 页面和本地静态资源；页面 CSS/JS 均为同源资源。
- A/B 顶部按钮标签均为“重置演示”；C/D 分别为“重置 C”“重置 D”。服务状态为单进程内存，不是持久化环境。
