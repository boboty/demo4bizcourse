# 四 Demo 统一课堂彩排

统一使用一个 `make dev` 服务和 `http://127.0.0.1:8016`。建议投影窗口至少 1440×900；所有数据、身份和 AI 结果均是本地虚构或离线确定性模拟。不要录入真实资料。

| 顺序 | 时间建议 | 现场步骤 | 预期与停顿 | 复位 |

主演示总计约 95 分钟；入口切换和每讲过渡建议各留 1–2 分钟。课程中的其余页面依 [62 页逐页映射](DEMO_COURSE_MAPPING.md) 讲授或互动，不要求每页打开 Demo。

## 课前与课后检查

1. 课前确认依赖已安装；断网后在 `ai-security-demo/` 执行 `make dev`。健康提示应显示本地服务正常，四页顶部各有唯一的 A/B/C/D 导航入口。
2. 彩排顺序按 A → B → C → D 切换；每次只重置当前课程，确认其余页面已建立的运行或状态保持不变。切换再切回、刷新页面后检查状态仍由同一后端运行管理。
3. 讲解完后分别重置 A、B、C、D，确认旧 run 不再有效，最终停在四 Demo 初态。

## 故障和备用

- 若任何请求失败，页面会显示错误提示和 request ID。检查启动 `make dev` 的终端，服务恢复后刷新页面，只重置当前 Demo 并从头操作。课堂验证中可用 Playwright 本地拦截器复现一次接口 503 与恢复；该错误由测试脚本注入，不代表生产服务故障。
- 浏览器无法操作时，在同一已启动服务下运行 `uv run --offline python scripts/http_smoke_integrated.py`，以真实 HTTP 演示关键业务链，并明确这是 HTTP 备用路径。B 页面另有“状态查询”展示，已接受实现用于说明只读返回，不声称它与课件摘要输出逐字相同。
- 若服务无法恢复，继续按本地课件和本剧本讲解，等待重新启动后再做实机流程。没有录屏；已保存的截图只作为静态辅助证据，不能称为本次现场操作。
- 8016 被占用时先核实进程归属。本课程脚本默认 8016；未经确认不要终止未知进程。恢复到标准端口后再继续。
