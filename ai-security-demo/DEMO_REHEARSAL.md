# 四 Demo 统一课堂彩排

本安排按 6 小时净授课（360 分钟）、四讲各 90 分钟估算；如课程日程把茶歇/午餐计入 6 小时，应从讲授段相应扣除并由 Human 彩排校准。时间是规划区间，不是保证完成时间。页面与操作依据定稿 62 页课件及当前真实界面。

## 全天时间口径

| 讲次 / 课件范围 | 分钟 | 安排 |
| --- | ---: | --- |
| 第一讲：数据流动、访问边界与责任 | 90 | 第 1–16 页讲授、互动与案例；第 17 页 Demo A 完整教学环节 12–15 分钟：纯操作 4–6 分钟，讲解/提问/互动 8–9 分钟；第 18–20 页回顾与收口。 |
| 第二讲：提示词注入、权限与审计 | 90 | 第 21–29 页概念、提问；第 30 页 Demo B 完整教学环节 12–15 分钟：纯操作 3–5 分钟，讲解/提问/互动 9–10 分钟；第 31–38 页复盘和结论。 |
| 第三讲：合规治理与人工认定 | 90 | 第 39–44 页机制与角色；第 45 页 Demo C 完整教学环节 15–18 分钟：纯操作 5–7 分钟，讲解/提问/互动 10–11 分钟；第 46 页回顾；第 47–50 页伦理场景、互动和收口。 |
| 第四讲：AI 辅助安全运营 | 90 | 第 51–53 页运营闭环；第 54 页 Demo D 完整教学环节 15–18 分钟：纯操作 5–7 分钟，讲解/提问/互动 10–11 分钟；第 55 页四栏回顾；第 56–62 页互动、路线与问答。 |
| **合计** | **360** | 四个 Demo 完整教学环节约 54–66 分钟；其中纯操作约 17–25 分钟，讲解/提问/互动约 37–41 分钟。其余时间用于课件讲解、讨论、提问、转场和收口，不额外堆叠操作。 |

每个 Demo 完整环节 = 纯操作 + 讲解/提问/互动。另可按课堂情况在选讲内容中安排深入讨论：A 误报、数据最小化与涉密边界；B 信任边界与纵深防御；C 证据充分性和适用制度；D 告警误报、漏报和处置授权。选讲讨论不计入上述必讲操作估算，应从本讲讲授/问答时间中调配，不承诺全部展开。

## Demo 转场、起点和复位

| Demo | 课件衔接 | 核心操作 | 最终结论 / 独立复位 |
| --- | --- | --- | --- |
| A | 第 16 页受控数据流 → 第 17 页演示 → 第 18 页口头回顾 | 规则识别 → 辅助误报 → 人工修正 → 脱敏预览 → 人工确认 | 识别不等于授权，后端独立检查权限；顶部“重置演示”。 |
| B | 第 29 页举手预测 → 第 30 页演示 → 第 31 页失败/防护机制 | 正常查询 → 污染文档 → 观察越权提案 → 故障模式执行 → 安全模式同提案 | 后端授权阻止越权；顶部“重置演示”。课件登录/四工具讲法须说明当前简化映射。 |
| C | 第 44 页角色分工 → 第 45 页演示 → 第 46 页证据阶梯 | 建立案例 → 规则线索 → 辅助解释 → 阅读并勾选原文证据 → 人工认定 | 规则/解释不等于认定，认定需要人和证据；“重置 C”。 |
| D | 第 53 页职责泳道 → 第 54 页演示 → 第 55 页四栏复盘 | 汇总日志 → 聚合异常 → 辅助研判 → 人工核查 → 四栏简报 | AI 推测不能当事实，处置需授权；“重置 D”。 |

四个页面由同一单进程服务提供。不要为转场重复启动服务；如只需讲课件回顾页，不重复点击 Demo。逐页标题、ID 和备注映射见 `DEMO_COURSE_MAPPING.md`。

## 课前彩排顺序

1. 依 `CLASSROOM_ENV_CHECKLIST.md` 离线启动、检查四入口和静态资源，确认页面健康提示正常。
2. 按 A→B→C→D 跑一遍主线；只操作本讲所需步骤，暂停并说出演示结论，测量真实用时。
3. 验证各自重置只影响当前 Demo；可额外验证服务重启后内存状态恢复初态。
4. 现场时间以 Human 最终彩排为准；若超时，优先保留关键转折和结论，删减可选深挖，不增加人为操作。

## 故障处理与备用

页面请求失败时先读页面错误提示/请求标识并查看服务终端；服务恢复后刷新并重置当前 Demo。浏览器不可用但服务仍正常，相关 runbook 列出的 HTTP smoke 脚本可作为技术备用，需向学员说明这是接口路径，不是页面流程。服务不可用时继续使用本地课件和讲师剧本，不把历史截图或 smoke 输出说成当前页面体验。端口 8016 的占用处理见环境清单。
