GATE 01

测试 Gate

GATE

确认课堂开始前的工程测试基线为 34 tests PASS。

LIVE

课堂观察点

失败 / fallback 处理

不要把普通报错当成 Route C 入口。转入课前保存的真实 failure bundle，并明确是 FALLBACK。
