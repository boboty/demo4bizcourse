AI研发验证闭环课堂演示

从一句模糊需求，到可以被证据证明的最终结果

需求未实现→ 功能出现但边界失败→ 测试通过但目标未达→ 目标与证据闭环

课堂使用提示（讲师用，点击展开 / 收起）
  • 建议先完整演示 Demo 1（00 → 01 → 02 → 03），状态页右上角可切换上一个 / 下一个状态。
  • 01 中先保持默认条件导出成功，再筛选 bob 触发空值失败。
  • 02 中导出后打开文件核对只有当前页 8 条，并展开请求详情查看 page 参数。
  • 03 中展开请求详情，对比列表请求与导出请求的参数差异。
  • 再演示 Demo 2：同一个任务，改由完整任务包一次性交办，观察执行闭环如何一次走完。
  • “显示讲师说明 / 隐藏讲师说明”的偏好会带入每个页面（含 Demo 2）。

Demo 1 · 从模糊需求到可验证任务

通过四个结果状态，观察一句模糊需求如何遗漏边界，并最终形成完整任务包。

00 · Baseline

需求尚未实现

列表、筛选和分页已经存在，Excel导出仍待实现。

预期现象：点击导出只提示功能待实现，不调用真实导出接口。

进入演示 →
01 · One-line Implementation

功能出现，但边界失败

一句话交办后，普通数据可以导出，但空姓名记录会导致失败。

预期现象：默认导出成功；筛选固定空值用户后导出失败。

进入演示 →
02 · Tests Green, Goal Missed

测试通过，但原始目标未达

空值已经修复，文件也合法，但23条数据只导出当前页8条。

预期现象：页面显示共23条，Excel中只有当前页8条。

进入演示 →
03 · Final Pass

目标、边界与证据闭环

导出全部筛选结果，不受分页限制，并通过完整验收。

预期现象：默认导出23条；组合筛选导出正确；导出请求不携带分页。
