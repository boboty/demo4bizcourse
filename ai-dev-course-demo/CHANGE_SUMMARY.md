# 变更说明

## 完成内容

- 新增 `GET /api/users/export`，按列表的 `username`、`status` 筛选口径导出 xlsx。
- 新增 `UserExportService`，复用 `UserService.search_users` 和已有 `build_excel`。
- 固定六列中文表头；空列表生成只有表头的合法工作簿。
- `display_name=None` 在导出映射边界转换为空字符串。
- 匹配结果超过 10000 行时返回 HTTP 422 和明确错误，不静默截断。
- 补充接口/服务测试，以及 Demo 1、Demo 2、检查点、运行与兜底文档。
- 根据独立验收统一五个检查点的安全脚本：安装脚本可重复执行，重置只清理演示实现目录，并新增无损切回 `main` 的恢复脚本。

## 真实验证链路

- `demo-baseline`：11 项基础测试通过。
- `demo-validation-failed`：1 失败、17 通过；真实失败为 `NoneType` 调用 `.strip()`。
- `demo-fixed`：19 项测试通过，`real 0.74` 秒。
- 最终交付：25 项测试通过，`real 0.62` 秒；同时校验任务包/七节点资产一致性和 HTTP 422 超限响应。
- 安全复验：隔离 clone 中连续两次安装成功；五个检查点逐一验证重置与恢复，根目录讲师笔记、截图和 `.venv` 均保留。

## 风险与限制

- openpyxl 写入空字符串后重新加载时返回空单元格值 `None`；服务映射测试验证写入值为 `""`，接口测试验证最终单元格为空。
- 10000 行导出当前在内存中一次性构建，符合课程上限和小型演示规模，不面向大数据量生产流式导出。
- 当前环境没有完成真实录屏和七张界面截图，已提供录屏脚本、截图清单和 Git 兜底检查点，未用占位图冒充。
