# Source of Truth｜汇损 + 退税候选判定

这份文件是 Demo 3 独立验收时的**业务规则唯一事实源**。

## 规则

1. 当“汇损候选”和“退税候选”同时具备资格时，必须**先评估「汇损 + 退税」双候选**。
2. 如果双候选没有命中排除条件，应选择：`FX_LOSS_PLUS_TAX_REFUND`，金额 = 汇损金额 + 退税金额。
3. **只有双候选被排除后**，才允许回退到 `TAX_REFUND_ONLY`。
4. 如果只有退税候选具备资格，可选择 `TAX_REFUND_ONLY`。
5. 如果退税候选不具备资格，本演示数据集返回 `NO_CANDIDATE`。

## 关键提醒

“同时存在两个候选”不是“从两个候选里任选一个”。
这里的第一候选本身就是**组合候选**。退税单候选是组合候选被排除后的回退路径。
