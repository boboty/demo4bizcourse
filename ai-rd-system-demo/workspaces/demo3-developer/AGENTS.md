# 当前 Demo 工程规则

- 当前目录就是完整项目上下文，不读取父目录或兄弟 workspace，也不要在仓库里寻找课堂材料。
- 本工程统一使用 Python 3.12 和 pytest；不引入新的第三方依赖。
- 修改 Python 后运行 `../../.venv/bin/python -m pytest -q`（或 `./verify.sh`），开发侧测试是交付契约的一部分。
- 完成任务后可以运行 `./bin/self-check` 做开发侧自检，自检依据见 `SELF-CHECK.md`。
- 开发侧测试和自检只能证明实现与测试彼此一致，业务正确性仍需独立责任验证；本目录不包含独立验收标准。
