# 开发侧自检要求｜Level 3

这是开发完成前要执行的检查清单，不是独立验收器，也不包含第三讲的 Golden Case。

1. 修改完成后从当前 workspace 运行现有 pytest；若失败，修复后重新运行，直到结果可说明。
2. 检查客户名称筛选、融资状态筛选和组合筛选；覆盖空结果或边界输入的处理。
3. 检查数据权限仍由 `X-User` 和 tenant scope 控制，筛选不能绕过它。
4. 检查导出复用已有异步 export queue，并保留筛选条件和权限上下文。
5. 检查 `git diff --check`、`git diff --stat` 和完整 diff，确认修改边界只服务于本任务。
6. 完成说明列出实际执行的测试、功能检查、权限检查、导出检查和 diff 检查；不要声称没有执行的检查。
