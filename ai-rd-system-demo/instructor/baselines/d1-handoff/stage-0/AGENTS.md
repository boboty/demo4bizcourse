# Workspace rules

- 当前目录就是本次任务的完整项目上下文，不读取父目录或兄弟 workspace，也不要在仓库里寻找课堂材料。
- 只在当前 workspace 内检查和修改文件。
- 上一个 session 可能已经结束，这里没有可用的历史聊天记录。请先从工程现场重新建立坐标：`TASK.md`、`PROGRESS.md`、`DECISIONS.md`、`feature-list.json`、`./verify.sh`、`git log`。
- `PROJECT-MEMORY.md` 和 `CODING-STANDARDS.md` 是长期项目事实和代码规范，不会随任务进度变化；`PROGRESS.md`／`DECISIONS.md`／`feature-list.json` 才是当前任务的实时状态。
- 完成本次工作后，请把最新状态写回 `PROGRESS.md`（以及必要时的 `DECISIONS.md`、`feature-list.json`），供下一个 session 使用。
