# 旧版 Demo 材料（存档）

本目录保存上一版「AI 测试闭环」课堂演示（`/api/orders/discount-preview` + VIP 优惠券）的
全部材料：业务文档、两套测试资产、运行脚本、课堂脚本、实验记录与幻灯片证据。

它们**不属于**当前「AgentAI 驱动软件测试」课堂 Demo 的一部分：

- 当前 Demo 的业务 Source of Truth 是 `docs/business-rules.md`；
- 当前 Demo 的课堂 Agent 工作区是 `agent_workspace/`；
- 当前 Demo 的默认测试只有 smoke（见 `tests/test_smoke.py`）。

如需恢复旧版 Demo，把本目录内容移回仓库根目录并还原 `app/`、`scripts/`、`README.md`
（均可从 git 历史找回）。
