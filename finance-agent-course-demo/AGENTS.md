# 财务课程 Demo 项目规则

## 范围

- 本项目是离线课堂演示，不是真实财务生产系统。
- 不调用真实大模型、外部 API、数据库、外部 CDN 或在线字体。
- 所有 AI 推理、工具调用、知识检索和业务结果均来自固定 fixture 与预设状态。
- 不修改仓库中的 `ai-dev-course-demo/` 旧项目。

## 技术栈

- Python 3.11+
- FastAPI、Uvicorn、pytest、httpx
- 原生 HTML、CSS、JavaScript
- 无前端构建工具、无数据库

## 业务边界

- 金额相同不是充分业务证据。
- 有歧义的收款不能自动核销。
- AI 可以查询、分析、生成建议和凭证草稿，但不能自动过账。
- 缺少决定性资料时必须停止并创建待确认任务。
- 最终业务归属由会计确认。
- 不展示模型私有思维过程，不把课堂页面做成真实财务系统复刻。

## 变更规则

- 新场景优先复用本项目内的主题、控制器和组件样式。
- 场景数据和讲师文案保持固定、可重复，不引入随机行为。
- 每个场景必须有独立 URL、重置能力和最小自动化验证。
- 不为一次性课堂需求建设通用低代码平台。
