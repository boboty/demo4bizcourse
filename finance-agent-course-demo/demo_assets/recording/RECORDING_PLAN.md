# 录屏计划

本轮不要求生成完整视频，也不把计划描述成已录制素材。

## 录制准备

1. 运行 `./scripts/test.sh`。
2. 启动 `./scripts/run.sh`，确认端口为 8001。
3. 使用 1366×768 浏览器窗口，关闭通知和无关窗口。
4. 默认隐藏讲师说明，关键讲解时再显示。
5. 每个演示单独录制，保留页面 URL 和当前步骤。

## 录制顺序

1. 总览页和统一业务背景。
2. 知识回答对比的第 01、04、05 步。
3. 批量工作流的第 01、05、06 步。
4. 异常智能体的第 04、06、07、08 步，必要时录制可选尾声。
5. 独立验收的第 02、04、06、07 步。
6. 月结的第 02、04、05 步。

## 降级方案

- 现场等待超过课堂节奏：用步骤下拉菜单或“直接最终结果”。
- 浏览器不稳定：使用 `SCREENSHOT_PLAN.md` 中的关键画面。
- 完整录屏不可用：使用 `DEMO_RUNBOOK.md` 和 `demo_assets/speaker_notes/` 手动讲解。
