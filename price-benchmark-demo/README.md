# 今日采购价格对标

一个完全使用本地演示数据的 FastAPI Web Demo。Python 3.12+，无需数据库、外网、真实市场或客户接口。

## 启动

```bash
cd price-benchmark-demo
make dev
```

首次运行会自动创建 `.venv` 并安装依赖；此后直接启动。打开 http://localhost:8000 。端口固定为 8000。正式演示前完成首次安装，演示过程中无需外网。

## 演示路径

- **Demo 1**：Reset → 开始执行 → 约 7 秒业务进度 → 结果页 → 任意商品“查看依据”。土豆、西红柿、黄瓜形成价格判断；大白菜因等级、毛净菜、运费口径不同暂不可比；青椒因市场价格过时等待人工确认。
- **Demo 2**：右上“演示控制”→“运行异常场景”→ 观察四个异常事件 → 报告 A → 点击“查看依据”看到依据缺口 → 报告 B → A/B 对比。也可直接跳到任一结果。
- 快捷键：`1` 正常场景，`2` 异常场景，`R` Reset。

## 3 分钟现场操作脚本

| 时间 | 操作 | 讲述重点 |
| --- | --- | --- |
| 0:00–0:20 | 从 Reset 首页点击“开始执行” | 任务是今日采购价格对标，共 5 个商品、5 个市场来源。 |
| 0:20–0:50 | 看进度进入 Demo 1 结果 | 系统先判断口径是否可比。 |
| 0:50–1:20 | 展开土豆和大白菜“查看依据” | 土豆由程序做单位换算；大白菜缺少净菜、等级和运费转换依据，不能硬算价差。 |
| 1:20–1:40 | 点击“运行异常场景” | 观察缺数据、字段改名、访问失败、规格不确定四个事件。 |
| 1:40–2:10 | 看报告 A，展开西红柿/黄瓜依据 | A 的 100% 完成掩盖推断值和未经核验的来源；错误结论与正常场景明显不同。演示数据固定，非模型现场生成。 |
| 2:10–2:40 | 切换报告 B，展开停止项依据 | 3 项完成（含 1 项“暂不可比”的口径判断）、2 项停止；黄瓜卡片直接标出来源失败与核验快照，缺数据时不补值。 |
| 2:40–3:00 | 切到 A/B 对比，最后按 R | 总结“错了，但看起来已经完成”的风险。 |

## 验证

```bash
make test
```

价格换算和偏离由 `app/pricing.py` 的 `Decimal` 函数完成。报告 A 是预置的风险示例，不参与受控结果计算。页面只加载本机 `/api` 和 `/static` 资源。
